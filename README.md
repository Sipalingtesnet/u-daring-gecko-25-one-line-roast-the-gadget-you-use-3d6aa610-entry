**Roast:** "Palm rejection on my laptop is flawless: my thumb is invisible while I type, then it reads my palm the moment I pause, so the cursor lands ten minutes in the past."

The line takes the trackpad's most-advertised feature and flips it into the exact reason the cursor betrays you mid-sentence — the palm it was built to ignore is only ignored until you stop to think.

## Run it

```
python3 main.py
```

Writes the roast to `/output/entry.txt`.
